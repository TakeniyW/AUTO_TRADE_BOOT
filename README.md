# 刘一策略 · 虚拟币合约交易终端

一个本地运行的永续合约量化交易终端：内置可自定义的「刘一策略」，支持历史回测、币安测试网模拟、币安 / 欧易实盘自动交易，自带中文 Web 仪表盘。

> 仅供学习与研究，不构成投资建议。合约交易风险极高，实盘前请先在测试网充分验证。

## 功能

- **自定义策略**：EMA 快慢线交叉、目标净收益、连续失败加仓、达标后跳过交叉、杠杆上限、峰值权益驱动仓位增长等参数全部可在页面调整，可另存为多个预设。
- **历史回测**：一键拉取币安 / 欧易历史 K 线（无需 API Key），展示收益、回撤、胜率、盈亏比、杠杆、手续费、资金费等指标，以及权益曲线、价格信号图与逐笔成交。
- **纸面实时**：用实时行情模拟撮合，不连接私有接口，适合快速验证参数与运行状态。
- **币安测试网**：使用 Futures Testnet 独立 API Key，真实下单撮合，行情来自测试网实时数据。
- **实盘交易**：支持币安 U 本位永续与欧易永续，热门币种下拉选择（ETH、BTC、SOL 等，共 20 个），按策略自动开平仓、反手、加仓、全平。
- **实时监控**：SSE 推送权益、持仓、成交、日志，断线自动降级为轮询。

## 快速开始

环境要求：Python 3.11+（开发环境为 3.14）。

```bash
cd /workspace
./run.sh                 # 自动建虚拟环境、装依赖并启动
# 或手动：
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。

首次启动会在 `data/` 下自动创建行情数据库、配置与密钥文件。

## 使用流程

1. **数据中心**：选择数据源（币安 / 欧易）、币种、周期与日期范围，点击「同步数据」。币安走公共归档，无需 Key；归档通常延迟 1 天，最新缺口会自动用日度文件补齐。仓库已内置 ETH/USDT 15m 演示数据（2024-01-01 ~ 2026-10-31，99,360 根）。
2. **策略回测**：选择数据源与时间范围，点击「运行回测」。本地数据覆盖不足时会自动同步。
3. **策略参数**：调整参数后「保存参数」，可「另存为预设」；「恢复刘一策略默认」可随时还原。
4. **交易台**：
   - `纸面模拟`：不填 Key，直接启动。
   - `测试网`：先在「设置」填写币安测试网 Key / Secret，再选择模式启动。
   - `实盘`：先在「设置」填写对应交易所 Key，勾选风险确认，并在启动框输入 `START LIVE` 二次确认。

## API Key 与交易所配置

在「设置」页填写，保存在本地 `data/secrets.json`（权限 600），接口返回时始终掩码。

| 槽位 | 用途 | 所需权限 |
| --- | --- | --- |
| 币安主网 | 实盘 | 合约交易（建议关闭提现） |
| 币安测试网 | 测试网 | 合约交易（<https://testnet.binancefuture.com> 申请） |
| 欧易 | 实盘 | 合约交易 + 读取，需填写 Passphrase |

- 建议为 API Key 绑定 IP 白名单并关闭提现权限。
- 欧易在部分地区 / 网络下不可直连，请在「设置 → HTTP(S) 代理」填写代理（如 `http://127.0.0.1:7890`），行情、回测同步与交易都会使用该代理。
- 程序会自动读取环境变量 `HTTPS_PROXY` / `HTTP_PROXY` 作为兜底。

## 刘一策略规则

| 项目 | 默认设定 |
| --- | --- |
| 交易对 | ETH/USDT 永续 |
| 周期 / 信号 | 15m；EMA25/99 交叉，收盘定信号、下一根开盘成交 |
| 初始资金 / 基础仓位 | 10,000 / 10,000 USDT（仓位为名义价值） |
| 目标收益 | 单笔净收益 ≥ 仓位的 7%（按扣费后净额反解止盈价） |
| 加仓 | 连续 4 笔未达标 → 仓位 + 基础仓位的 50%（1 万→1.5 万→2 万…） |
| 达标后 | 仓位回基础值，并跳过 20 次交叉 |
| 出场 | 无独立止损，下一次反向交叉平仓并反手 |
| 杠杆 | 上限 30x（按仓位/权益推算，超出钳制） |
| 仓位增长 | 峰值权益每 +1000，基础仓位 +500 |
| 资金 | 不复利提取、不重置，利润留在账户 |
| 成本 | taker 0.05%/边，资金费 0.01%/8h |

## 说明与注意事项

- 纸面模式权益从「初始资金」起算；实盘 / 测试网从账户实际 USDT 权益起算。
- 实盘启动时会将本地记录与交易所实际仓位对齐；检测到爆仓会立即停止引擎。
- 目标止盈按「净收益 ≥ 仓位 × 目标比例」反解价格，已计入双边手续费；资金费在每 8 小时结算点扣减。
- 币安主站公共接口在部分网络不可达时，纸面模式会自动回退到币安测试网行情，界面会明确提示。
- 行情数据来自交易所公共接口，实盘成交以交易所回报为准；网络异常时引擎会记录错误并继续重试。
